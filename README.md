# Le Laboratoire de Scorlia

Versions restaurées de douze expériences HTML/CSS/JavaScript historiques. Chaque dossier contient exactement la démonstration autonome exécutée dans Scorlia Portfolio V2, sans dépendance au portfolio ni à GitHub. Les styles et scripts sont intégrés dans index.html.

## Lancer les démonstrations

Télécharger le dépôt, puis ouvrir le fichier index.html d'une expérience dans un navigateur. Pour servir les fichiers localement :

```sh
python -m http.server 8000
```

Ouvrir ensuite http://localhost:8000. Aucune installation ni clé n'est nécessaire. Les cadres du portfolio transmettent uniquement le thème et l'état visible/invisible ; les démos fonctionnent aussi seules.
